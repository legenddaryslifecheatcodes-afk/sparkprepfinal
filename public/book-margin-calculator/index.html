Why margins and bleed get books rejected

The inside margin (the gutter) is the edge that goes into the fold. Thicker books need a bigger one, or words disappear into the spine. The outside margins keep text away from the edge the printer trims. Bleed is extra picture or color past the edge, so nothing white shows after trimming. If any of these are off, KDP and IngramSpark send the file back.

IngramSpark margins

IngramSpark's rejection notices say it plainly: "All text, borders, and important elements need to be at least 0.5 inch (13 mm) from trim edges." That goes for every side. A thick book needs extra room on the inside edge, because the fold eats into it.

How bleed changes your page size

If anything runs off the edge of the page, your PDF page must be bigger than your book: 0.125" wider and 0.25" taller. For a 6" x 9" book that's 6.125" x 9.25". If nothing runs off the edge, set your page to the exact trim size and don't add bleed.

How to set margins in Word

  1. Layout → Size → More Paper Sizes: type your trim size (or the bleed size from above).
  2. Layout → Margins → Custom Margins: set Multiple pages to Mirror margins.
  3. Type the inside and outside numbers from this calculator. Top and bottom use the outside number or more.
  4. Save as PDF and check the page size in Acrobat (File → Properties) before you upload.

Quick answers

What is the minimum gutter margin for KDP?

KDP's minimum inside margin depends on page count: 0.375 inch for 24 to 150 pages, 0.5 inch for 151 to 300, 0.625 inch for 301 to 500, 0.75 inch for 501 to 700, and 0.875 inch for 701 to 828 pages.

What margins does IngramSpark require?

IngramSpark asks for all text and important elements to be at least 0.5 inch (13 mm) from every trim edge.

How much bleed does a print book need?

0.125 inch on the top, bottom and outside edge. So a book with bleed has a PDF page 0.125 inch wider and 0.25 inch taller than its trim size.
