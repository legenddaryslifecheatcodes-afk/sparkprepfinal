How it works

  1. Send your file and the rejection message. Tap the button above. Tell us the printer, book size and page count.
  2. We fix it. Usually within 24 hours, often the same day.
  3. You see the proof. We send a preview of the fixed file showing it passes the printer's rules.
  4. Pay only if you're happy. Card, Apple Pay or Cash App. Then you get the final print-ready file.

What we fix

  • Wrong spine width for your page count
  • Missing bleed or a white line on the edge
  • Text or pictures too close to the edge
  • Wrong page size (like letter size for a 6x9 book)
  • Blurry or low resolution pictures
  • Fonts not embedded
  • Too much ink or color in a black and white book
  • Leftover template boxes on the cover
