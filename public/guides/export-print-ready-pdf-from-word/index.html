How to export a print-ready book PDF from Microsoft Word

Updated November 4, 2026 · Amazon KDP · IngramSpark · Barnes & Noble Press · Lulu

Most rejected interiors were made in Word. Word can make a good print file, if you change a few settings first.

1. The error

Interior file rejected (page size, margins, fonts or images)

Not one error, but the four most common ones a Word file runs into.

2. Why the printer rejected it

Word is built for letter-size office documents, not books. Out of the box it uses the wrong page size, its margins don't account for the spine, it can leave fonts out of the PDF and it shrinks pictures when saving. Each of those is its own rejection reason.

3. The do-it-yourself fix

1. Page size

  1. Layout → Size → More Paper Sizes → enter your trim size (for example 6" x 9"). Apply to: Whole document.

2. Margins

  1. Layout → Margins → Custom Margins → Multiple pages: Mirror margins.
  2. Inside margin by page count (see our KDP margin guide); at least 0.5" on every side for IngramSpark.

3. Pictures

  1. File → Options → Advanced → Image Size and Quality → tick Do not compress images in file, Default resolution: High fidelity.

4. Export

  1. File → Save As → PDF → Options → tick PDF/A compliant so all fonts are embedded.
  2. Open the PDF and check page size, page count and that nothing sits too close to the edges.

Quick answers

Can I use Word to format a book for KDP?

Yes. Set the paper size to your trim size, use mirror margins with the right inside margin, turn off image compression and save as a PDF/A compliant PDF.

Why is my Word PDF rejected?

Usually the page size is still letter size, the margins are too small for the page count, fonts aren't embedded or images were compressed below 300 DPI.
