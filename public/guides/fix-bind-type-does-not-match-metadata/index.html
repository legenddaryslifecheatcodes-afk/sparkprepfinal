How to fix "bind type/trim size does not match the metadata"

Updated October 31, 2026 · IngramSpark

Your cover can look perfect and still be built for the wrong kind of book. This error means the file's shape doesn't match what you told IngramSpark you're printing.

Why you get “BIND TYPE/TRIM SIZE OF THE JACKET FILE ... DOES NOT MATCH THE METADATA”

"Metadata" is the book setup you filled in: paperback or hardcover, case laminate or dust jacket, and trim size. Each one needs a cover file of a completely different shape.

A paperback cover is back + spine + front with 0.125" bleed. An IngramSpark case laminate hardcover wraps around boards, so it needs 0.625" of wrap and a 0.5" hinge on each side of the spine. A dust jacket adds two 3.25" flaps and 0.25" folds. Upload a paperback-shaped file for a jacket book and the sizes are off by inches, so it's rejected.

How to fix “BIND TYPE/TRIM SIZE OF THE JACKET FILE ... DOES NOT MATCH THE METADATA” manually (the hard way)

If you want to try adjusting the files yourself, here are the steps you need to follow:

  1. Check your title setup in IngramSpark: binding (paperback, case laminate or dust jacket) and trim size.
  2. Download IngramSpark's cover template for exactly that binding, trim size and page count.
  3. Open your cover file and set it to the template's full size.
  4. Move your back, spine, front (and flaps, for a jacket) to line up with the template, hide the template layer, and re-export as PDF/X-1a:2001.
  5. Re-upload it to your printer and wait for the file review again. If it fails, you start over.

Quick answers

Does a dust jacket hardcover need a different cover file than a case laminate?

Yes. A jacket has two 3.25" flaps and 0.25" folds; a case laminate wraps around the boards with 0.625" of wrap. They are different sizes and can't be swapped.

Does KDP offer dust jackets?

No. KDP hardcovers are case laminate only, so a dust jacket file is an IngramSpark (or Lulu, Barnes & Noble Press) thing.
