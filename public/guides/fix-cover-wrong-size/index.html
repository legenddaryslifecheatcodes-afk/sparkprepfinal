How to fix "cover dimensions are incorrect"

Updated October 28, 2026 · Amazon KDP · IngramSpark · Barnes & Noble Press · Lulu

A paperback cover isn't the size of your book. It's the back, spine and front laid out flat, plus bleed, and it has to be exact.

The error: “The cover file dimensions do not match the required size for this book”

Why you get “The cover file dimensions do not match the required size for this book”

The full cover size depends on three things: your trim size (like 6" x 9"), your spine width (from page count and paper) and bleed (0.125" around the outside). For a 6" x 9" paperback the height is 9.25", and the width is 0.125" + 6" + spine + 6" + 0.125".

If any one of those is off, even by a fraction of an inch, the printer's system rejects the cover. The most common causes: making the cover at trim size with no bleed, using the wrong paper type, or the page count changing after the cover was made.

How to fix “The cover file dimensions do not match the required size for this book” manually (the hard way)

If you want to try adjusting the files yourself, here are the steps you need to follow:

  1. Note your trim size, your final page count and your paper (white or cream).
  2. Get the exact full cover size from your printer's own cover calculator or template.
  3. Open your cover file and change the document size to exactly that width and height.
  4. Move the back, spine and front art so each panel sits in the right place, then re-export as PDF/X-1a:2001.
  5. Re-upload it to your printer and wait for the file review again. If it fails, you start over.

Quick answers

What size is a 6x9 paperback cover?

The height is 9.25" (9" plus 0.125" bleed top and bottom). The width is 12.25" plus your spine width, because it's 0.125" + 6" + spine + 6" + 0.125".

Why did my cover size change?

Spine width depends on page count and paper. If either changes, the full cover width changes too.
