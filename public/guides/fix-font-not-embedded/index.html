How to fix the "font not embedded" error in your book PDF

Updated November 20, 2026 · Amazon KDP · IngramSpark · Barnes & Noble Press · Lulu

An unembedded font is a font your PDF names but doesn't carry inside it. The printer's computer doesn't have it, so the file is rejected.

What does "font not embedded" mean? It means your PDF names a font but doesn't carry it inside the file. Printers require every font to be embedded so your book prints exactly as designed. Fix it by turning on font embedding when you save as PDF, or by exporting as PDF/X-1a, which embeds all fonts.

Why you get “Font not embedded”

A PDF can either carry its fonts inside it (embedded) or just name them and hope the next computer has them. Printers require every font to be embedded, even common ones like Arial or Times, so your book prints exactly as designed.

If a font isn't embedded, the printer's system would swap in a different font. Words move, lines break in new places, and pages can shift, so they reject the file instead.

How to fix “Font not embedded” manually (the hard way)

If you want to try adjusting the files yourself, here are the steps you need to follow:

  1. Open your original manuscript or cover file.
  2. In Word, go to File → Options → Save and tick "Embed fonts in the file" (and untick "Do not embed common system fonts").
  3. Swap any font whose license doesn't allow embedding for one that does.
  4. Re-export as PDF/X-1a:2001, then check in Acrobat (File → Properties → Fonts) that every font says "Embedded" or "Embedded Subset".
  5. Re-upload it to your printer and wait for the file review again. If it fails, you start over.

Step by step in your app

Microsoft Word

  1. File → Save As → choose PDF.
  2. Click Options and tick PDF/A compliant ("ISO 19005-1 compliant"). This forces Word to embed every font.
  3. Save, then check the fonts in Acrobat (below).

Adobe InDesign

  1. File → Export → Adobe PDF (Print).
  2. Choose the preset PDF/X-1a:2001. It embeds all fonts.
  3. Export.

Adobe Acrobat Pro

  1. To check: File → Properties → Fonts tab. Every font should say "(Embedded)" or "(Embedded Subset)".
  2. To fix: Tools → Print Production → Preflight, search for Embed missing fonts and run the fixup.
  3. If a font can't be embedded, its license doesn't allow it. Switch to a font that does.

The most common mistake: Saving with "Save as PDF" from a browser or phone app, which often skips fonts. Use a print-quality PDF export instead.

How to check it's fixed before you upload again

  • Acrobat's font list (File, Properties, Fonts) shows "Embedded" or "Embedded Subset" next to every font.
  • No font says "Type 3" or has a blank where the embedded status should be.
  • Fonts inside pictures or charts were turned into outlines or the picture was flattened before export.

Quick answers

How do I check if fonts are embedded in a PDF?

Open it in Adobe Acrobat and go to File, Properties, Fonts. Each font should show Embedded or Embedded Subset.

Do standard fonts like Arial need to be embedded?

Yes. Printers need every font embedded, including Arial, Times and Helvetica, which many programs skip by default.
