How to fix the "font not embedded" error in your book PDF

Updated October 28, 2026 · Amazon KDP · IngramSpark · Barnes & Noble Press · Lulu

An unembedded font is a font your PDF names but doesn't carry inside it. The printer's computer doesn't have it, so the file is rejected.

1. The error

Font not embedded

Often listed with the font's name, such as "Font Garamond not embedded".

2. Why the printer rejected it

A PDF can either carry its fonts inside it (embedded) or just name them and hope the next computer has them. Printers require every font to be embedded, even common ones like Arial or Times, so your book prints exactly as designed.

If a font isn't embedded, the printer's system would swap in a different font. Words move, lines break in new places, and pages can shift, so they reject the file instead.

3. The do-it-yourself fix

Microsoft Word

  1. File → Save As → choose PDF.
  2. Click Options and tick PDF/A compliant ("ISO 19005-1 compliant"). This forces Word to embed every font.
  3. Save, then check the fonts in Acrobat (below).

Adobe InDesign

  1. File → Export → Adobe PDF (Print).
  2. Choose the preset PDF/X-1a:2001. It embeds all fonts.
  3. Export.

Adobe Acrobat Pro

  1. To check: File → Properties → Fonts tab. Every font should say "(Embedded)" or "(Embedded Subset)".
  2. To fix: Tools → Print Production → Preflight, search for Embed missing fonts and run the fixup.
  3. If a font can't be embedded, its license doesn't allow it. Switch to a font that does.

Quick answers

How do I check if fonts are embedded in a PDF?

Open it in Adobe Acrobat and go to File, Properties, Fonts. Each font should show Embedded or Embedded Subset.

Do standard fonts like Arial need to be embedded?

Yes. Printers need every font embedded, including Arial, Times and Helvetica, which many programs skip by default.
