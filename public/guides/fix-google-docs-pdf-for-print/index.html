How to fix a book interior written in Google Docs

Updated November 15, 2026 · Amazon KDP · IngramSpark

Google Docs is great for writing. But a PDF from Docs is set up for printer paper, not a book.

The error: “Interior page size does not match the trim size you selected”

Why you get “Interior page size does not match the trim size you selected”

Google Docs is built for office paper like Letter (8.5" x 11") and A4. Your book is probably 6" x 9" or 5.5" x 8.5". Upload a Letter-size PDF for a 6" x 9" book and the page size check fails.

Books also need a wider inside margin (the gutter) so words don't vanish into the spine. At KDP it grows with page count, from 0.375" up to 0.875". IngramSpark wants everything at least 0.5" from the edge. Docs doesn't set either for you.

How to fix “Interior page size does not match the trim size you selected” manually (the hard way)

If you want to try adjusting the files yourself, here are the steps you need to follow:

  1. In Google Docs, choose File → Download → Microsoft Word (.docx).
  2. Open it in Word and set Layout → Size → More Paper Sizes to your trim size (for example 6" x 9").
  3. Set Margins → Custom: choose Mirror margins and set the inside margin for your page count from your printer's table.
  4. Fix any pages that moved, then File → Save As → PDF, with fonts embedded.
  5. Upload it to your printer and check the previewer for margin and page size warnings.

Quick answers

Can I upload a Google Docs PDF to KDP?

Only if the page size matches your trim size and the margins meet KDP's table. A default Docs PDF is Letter size, so it won't.

What's the easiest way out of Google Docs?

Download as Word (.docx), then set the book size and margins in Word or import it into a book formatter.
