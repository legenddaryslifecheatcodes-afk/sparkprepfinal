How to fix a hardcover case laminate cover that's the wrong size

Updated November 8, 2026 · Amazon KDP · IngramSpark

Hardcover covers wrap around boards, so they need extra space that paperbacks don't. Each printer measures it differently.

Why you get “Cover dimensions do not match the hardcover template for this book”

A case laminate cover is printed, then wrapped around cardboard boards and glued inside. So it needs wrap (extra art that folds over the board edges) and, at IngramSpark, a hinge beside the spine.

  • IngramSpark: 0.625" wrap on every outside edge and a 0.5" hinge each side of the spine.
  • Amazon KDP: 0.591" wrap, with the hinge inside the cover panels instead of added on.

Hardcover spines also come from each printer's own table, not the paperback formula. Using a paperback size, or the other printer's numbers, gets the cover rejected.

How to fix “Cover dimensions do not match the hardcover template for this book” manually (the hard way)

If you want to try adjusting the files yourself, here are the steps you need to follow:

  1. Use your printer's own hardcover cover calculator or template with your exact trim size, page count and paper.
  2. Open your cover file and set it to that full size.
  3. Extend background art out to the wrap edge, and keep all text and faces out of the wrap and hinge areas.
  4. Re-export as a print PDF (PDF/X-1a:2001 if you can).
  5. Re-upload it to your printer and wait for the file review again. If it fails, you start over.

Quick answers

How much wrap does an IngramSpark case laminate cover need?

0.625" on every outside edge, plus a 0.5" hinge on each side of the spine.

Is a KDP hardcover cover the same size as IngramSpark's?

No. KDP uses a 0.591" wrap and different board and spine numbers, so build from each printer's own calculator.
