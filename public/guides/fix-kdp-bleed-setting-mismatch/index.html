How to fix a KDP interior that doesn't match your bleed setting

Updated November 3, 2026 · Amazon KDP

When you set up a paperback, KDP asks "Bleed" or "No bleed". Your PDF's page size has to match the answer exactly.

Your manuscript's page size doesn't match the trim size and bleed settings you selected

Paraphrased. Each printer words this a little differently.

Why did your file get rejected?

No bleed means nothing on your pages touches the edge, so each PDF page is exactly your trim size (for example 6" x 9").

Bleed means pictures or color run off the edge, so each page must be bigger: 0.125" wider and 0.25" taller (6.125" x 9.25" for a 6" x 9" book). If you pick bleed but upload trim-size pages, or the other way round, KDP flags it, or your pictures end up with white edges.

How to fix it manually (the hard way)

If you want to try adjusting the files yourself, here are the steps you need to follow:

  1. Decide: does anything on your pages need to touch the edge? If yes, you need bleed. If no, choose no bleed.
  2. Open your manuscript and set the page size to match: trim size for no bleed, or trim + 0.125" wide and + 0.25" tall for bleed.
  3. For bleed, stretch edge-to-edge pictures out to the new page edge; keep text inside the margins.
  4. Re-export as a PDF and make sure the KDP setup (Bleed / No bleed) matches what you built.
  5. Re-upload it and wait for the review again (KDP says a review can take up to 72 hours).

Quick answers

What size should a 6x9 interior PDF be with bleed?

6.125" x 9.25". Without bleed it's exactly 6" x 9".

Do I need bleed for a novel?

Usually not. You only need bleed when pictures, color blocks or shapes run off the edge of the page.
