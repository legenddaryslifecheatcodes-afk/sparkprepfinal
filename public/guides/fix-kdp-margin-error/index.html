How to fix a KDP margin error (with the gutter table)

Updated October 28, 2026 · Amazon KDP

KDP's inside margin grows as your book gets thicker. Most margin errors come from using one margin for every book.

1. The error

Text is outside the margins / content too close to the edge

Paraphrased. KDP shows this in its print previewer before you can publish.

2. Why the printer rejected it

The inside edge of each page (the gutter) disappears into the spine. Thicker books curve more, so KDP needs a bigger inside margin as the page count grows. The outside, top and bottom margins must be at least 0.25" (0.375" if your book has bleed).

Page countKDP minimum inside margin
24 to 1500.375"
151 to 3000.5"
301 to 5000.625"
501 to 7000.75"
701 to 8280.875"

Page numbers, headers and images count too. If anything sits closer to the edge than these numbers, KDP flags it.

3. The do-it-yourself fix

Microsoft Word

  1. Layout → Margins → Custom Margins.
  2. Set Multiple pages to Mirror margins.
  3. Set Inside to your number from the table, and Outside, Top and Bottom to at least 0.25" (we suggest 0.5" so text doesn't feel cramped).
  4. Check headers and footers: Layout → Margins → Layout tab, and keep them inside the margins.
  5. Save as PDF and upload again.

Adobe InDesign

  1. Layout → Margins and Columns (on the parent/master pages).
  2. Set Inside and Outside using the table above.
  3. Export with File → Export → Adobe PDF (Print).

Quick answers

What is the minimum gutter for KDP?

0.375 inches for 24 to 150 pages, 0.5 for 151 to 300, 0.625 for 301 to 500, 0.75 for 501 to 700 and 0.875 for 701 to 828 pages.

What are KDP's outside margins?

At least 0.25 inches without bleed and 0.375 inches with bleed, on the top, bottom and outside edges.
