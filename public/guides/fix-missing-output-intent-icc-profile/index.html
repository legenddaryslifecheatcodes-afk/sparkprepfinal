Why you get “PDF/X-1a output intent is missing or has no embedded ICC profile”

A PDF/X-1a file must carry an output intent: a note saying which printing conditions the colors were prepared for, usually with an ICC profile (a small color description) built in. That's how the printer knows how to read your CMYK colors.

Files often lose it when they're re-saved, merged or "optimized" in a different program, or when a tool labels a file PDF/X-1a without doing the full job. Checks then fail even though the pages look fine.

How to fix “PDF/X-1a output intent is missing or has no embedded ICC profile” manually (the hard way)

If you want to try adjusting the files yourself, here are the steps you need to follow:

  1. Go back to your original design file (InDesign, Affinity, Illustrator).
  2. Export again using the built-in "PDF/X-1a:2001" preset. Don't re-save it in another app afterwards.
  3. No InDesign? In Acrobat Pro, open Print Production → Preflight and run "Convert to PDF/X-1a", choosing a CMYK profile such as US Web Coated (SWOP) v2.
  4. Run Preflight again to confirm "PDF/X-1a compliant".
  5. Re-upload it to your printer and wait for the file review again. If it fails, you start over.

Quick answers

What is an output intent in a PDF?

A note inside a print PDF that says which printing conditions its colors were prepared for, usually with an ICC color profile embedded.

Which ICC profile should I use?

Use the one your printer recommends. US Web Coated (SWOP) v2 is a common choice for US book printing.
