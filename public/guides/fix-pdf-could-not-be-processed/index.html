How to fix "your file could not be processed"

Updated November 26, 2026 · Amazon KDP · IngramSpark · Barnes & Noble Press · Lulu

Before a printer can check your book, it has to open it. If it can't, you get a vague "could not be processed" message.

Why does my printer say my file could not be processed? Usually the printer's system can't open every page. Common causes are a password or security setting, even one that only blocks printing or editing; a damaged file from an export that stopped early or a bad download; or a file that isn't really a PDF, like a renamed Word or image file.

Why you get “Your file could not be processed. Please upload a valid PDF.”

Printers' systems need to open every page. The common reasons they can't:

  • A password or security setting, even one that only blocks printing or editing.
  • A damaged file from an export that stopped early, a bad download, or a file synced while still saving.
  • A "PDF" that isn't really one, like a renamed Word or image file, or a web "Print to PDF" with odd settings.

How to fix “Your file could not be processed. Please upload a valid PDF.” manually (the hard way)

If you want to try adjusting the files yourself, here are the steps you need to follow:

  1. Open the PDF on your computer. If it asks for a password or shows a lock, remove the security: Acrobat → File → Properties → Security → "No Security".
  2. If it won't open cleanly, go back to your original Word, InDesign or Canva file.
  3. Export a fresh PDF straight from that original (File → Save As / Export → PDF), not from a browser or a converter website.
  4. Open the new PDF and scroll through every page to check it's complete.
  5. Re-upload it to your printer and wait for the file review again. If it fails, you start over.

The most common mistake: Renaming a Word or image file to end in .pdf, or converting it on a free website, instead of exporting a real PDF from the original program.

How to check it's fixed before you upload again

  • Acrobat's File, Properties, Security shows "No Security".
  • The PDF opens without warnings and you can scroll through every page.
  • The file came straight from your original program's Export or Save As PDF.

Quick answers

Can I upload a password-protected PDF to KDP?

No. Remove any password or security settings before uploading.

Why does my PDF open on my computer but fail on KDP?

Security settings, a partly damaged export, or unusual PDF features can all pass on your screen but fail the printer's check. A fresh export from the original file usually fixes it.
