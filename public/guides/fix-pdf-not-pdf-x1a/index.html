How to fix "your file is not PDF/X-1a compliant"

Updated November 20, 2026 · IngramSpark · Barnes & Noble Press · Lulu

Not every PDF is a print PDF. PDF/X-1a is a stricter kind built for printers, and IngramSpark asks for it.

What does "not PDF/X-1a compliant" mean? It means your PDF breaks the PDF/X-1a print standard: it may have RGB colors, fonts that aren't embedded, live transparency, or no output intent. IngramSpark, Barnes & Noble Press and Lulu ask for PDF/X-1a. Fix it by exporting with a PDF/X-1a preset from InDesign, Affinity or Acrobat.

Why you get “The file is not PDF/X-1a compliant”

PDF/X-1a is a print standard. It requires CMYK or grayscale color (no RGB), every font embedded, no live transparency, and a note inside the file saying which printing conditions it was made for (the "output intent").

A regular "Save as PDF" from Word or a "PDF Standard" download from Canva doesn't meet those rules, so IngramSpark's checks flag it. Barnes & Noble Press and Lulu also ask for PDF/X-1a files. KDP doesn't require PDF/X-1a, but a PDF/X-1a file works there too.

How to fix “The file is not PDF/X-1a compliant” manually (the hard way)

If you want to try adjusting the files yourself, here are the steps you need to follow:

  1. Open your original file.
  2. Convert all color to CMYK (or grayscale for black and white pages) and embed every font.
  3. In InDesign, go to File → Export → Adobe PDF (Print) and pick the "PDF/X-1a:2001" preset. Word can't make PDF/X-1a by itself, so use Acrobat Pro: Print Production → Preflight → "Convert to PDF/X-1a".
  4. Run Acrobat's Preflight to confirm the file is PDF/X-1a compliant.
  5. Re-upload it to your printer and wait for the file review again. If it fails, you start over.

The most common mistake: Picking "High Quality Print" or "Press Quality" instead of the PDF/X-1a:2001 preset. Those are not the same thing.

How to check it's fixed before you upload again

  • In Acrobat, the Standards panel (or File, Properties, Description) says PDF/X-1a:2001.
  • All colors are CMYK or grayscale, with no RGB left over.
  • There is no transparency, no layers and every font is embedded.

Quick answers

Does IngramSpark require PDF/X-1a?

IngramSpark asks for PDF/X-1a:2001 files. It's the safest format to send them.

Can Word export PDF/X-1a?

No. Word's PDF export isn't PDF/X-1a. You need a tool like Acrobat Pro, InDesign or SparkPrep to make one.
