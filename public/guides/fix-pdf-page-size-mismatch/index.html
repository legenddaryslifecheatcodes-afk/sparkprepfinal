How to fix a PDF page size that doesn't match your trim size

Why you get “Interior page size does not match the trim size selected”

When you set up your book you choose a trim size, like 5.5" x 8.5" or 6" x 9". Your interior PDF has to be that exact size. Word and Google Docs start at letter size (8.5" x 11"), so a book typed there and saved as PDF is the wrong size unless you change it.

If your interior has pictures that run to the edge (bleed), KDP wants the page 0.125" wider and 0.25" taller than the trim size. Without bleed, the page is exactly the trim size.

How to fix “Interior page size does not match the trim size selected” manually (the hard way)

If you want to try adjusting the files yourself, here are the steps you need to follow:

  1. Open your manuscript in Word, Google Docs or InDesign.
  2. Go to Layout → Size → More Paper Sizes (Word) and type your exact trim size, for example 6" x 9". If your book has bleed, add 0.125" to the width and 0.25" to the height.
  3. Scroll through the whole book: pictures, tables and page breaks will have moved. Put them back.
  4. Re-export as a PDF. Don't use "Fit to page" or "Shrink to fit" when you save it.
  5. Re-upload it to your printer and wait for the file review again. If it fails, you start over.

Step by step in your app

Microsoft Word

  1. Layout → Size → More Paper Sizes.
  2. Enter your trim width and height (add 0.125" to the width and 0.25" to the height only if your book has bleed).
  3. Set Apply to: Whole document.
  4. Re-check page breaks, then File → Save As → PDF.

Google Docs

  1. File → Page setup → Paper size → Custom, and enter your trim size.
  2. File → Download → PDF document.

Adobe InDesign

  1. File → Document Setup: set the page size to your trim size.
  2. Export with File → Export → Adobe PDF (Print).

Quick answers

What size should my interior PDF be?

Exactly your trim size, such as 6 by 9 inches. If your interior has bleed, KDP wants it 0.125 inch wider and 0.25 inch taller.

Why is my Word PDF the wrong size?

Word starts every document at letter size (8.5 by 11 inches). Change the paper size to your trim size before saving as PDF.
