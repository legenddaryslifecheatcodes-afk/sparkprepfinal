How to fix "jacket layout not built to the correct specifications"

Updated October 28, 2026 · IngramSpark · Lulu · Barnes & Noble Press

A dust jacket isn't a paperback cover with a hard back. It has flaps and folds, and every piece has its own exact spot.

The error: “JACKET LAYOUT NOT BUILT TO THE CORRECT SPECIFICATIONS”

Why you get “JACKET LAYOUT NOT BUILT TO THE CORRECT SPECIFICATIONS”

A dust jacket, laid flat, is: bleed, back flap, fold, back cover, spine, front cover, fold, front flap, bleed. At IngramSpark the flaps are 3.25" wide and the folds 0.25", and each printer's template sets the exact sizes for your book.

Jackets are rejected when the file is built like a paperback cover (no flaps), when the sizes don't match the template, or when text runs over a fold, where it would wrap around the edge or sit in the crease.

How to fix “JACKET LAYOUT NOT BUILT TO THE CORRECT SPECIFICATIONS” manually (the hard way)

If you want to try adjusting the files yourself, here are the steps you need to follow:

  1. Download your printer's own dust jacket template for your exact trim size and page count.
  2. Open your jacket file and set it to the template's full size.
  3. Line up each panel with the template: flaps, folds, back, spine and front. Move any text off the folds and away from the edges.
  4. Hide the template layer and re-export as PDF/X-1a:2001.
  5. Re-upload it to your printer and wait for the file review again. If it fails, you start over.

Quick answers

How wide are dust jacket flaps at IngramSpark?

IngramSpark's jacket layout uses 3.25" flaps with 0.25" folds. Always build from the template for your exact trim size and page count.

Does a hardcover with a dust jacket need more than one cover file?

At IngramSpark, a jacketed hardcover needs a case cover file, a jacket file and the interior.
