Why you get “The PDF contains live transparency or layers that must be flattened”

Drop shadows, glows, faded images and see-through shapes are all transparency. Design programs also keep your art in layers. Printing systems can handle these unevenly, so a shadow can print as a box or a layer can go missing.

The PDF/X-1a print standard, which IngramSpark asks for, doesn't allow live transparency, so everything must be flattened into one finished image. KDP recommends flattening too.

How to fix “The PDF contains live transparency or layers that must be flattened” manually (the hard way)

If you want to try adjusting the files yourself, here are the steps you need to follow:

  1. Open your original file (InDesign, Illustrator, Photoshop or Canva).
  2. Flatten it: in Photoshop use Layer → Flatten Image; in InDesign or Illustrator use Object → Flatten Transparency (High Resolution).
  3. Check shadows, glows and faded areas still look right after flattening.
  4. Re-export as PDF/X-1a:2001, which also removes layers.
  5. Re-upload it to your printer and wait for the file review again. If it fails, you start over.

Quick answers

What does flattening a PDF mean?

It merges all layers and see-through effects into one finished image per page, so it prints exactly as it looks.

Does Canva flatten transparency?

When you download as PDF Print, tick the "Flatten PDF" box. Then check the PDF before uploading, especially pages with shadows or faded images.
