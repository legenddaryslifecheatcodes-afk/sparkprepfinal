What is PDF/X-1a, and how do you export it for your book?

Updated November 2, 2026 · IngramSpark · Barnes & Noble Press · Lulu · Amazon KDP

PDF/X-1a sounds like a code. It's just a strict kind of PDF that printers know will print the same every time.

1. The error: “File is not PDF/X-1a compliant”

File is not PDF/X-1a compliant

Paraphrased. Some printers require it; others strongly recommend it.

2. Why the printer rejected it

A normal PDF can hold things that confuse a printing press: screen colors (RGB), fonts that aren't included, see-through effects that print unpredictably. PDF/X-1a is a set of rules that forbids those:

  • every font embedded,
  • colors in CMYK or spot colors only,
  • see-through effects flattened,
  • the trim and bleed size written into the file.

IngramSpark asks for PDF/X-1a, and following it solves most other file errors at the same time.

3. The do-it-yourself fix

Adobe InDesign

  1. File → Export → Adobe PDF (Print).
  2. Adobe PDF Preset: [PDF/X-1a:2001].
  3. Marks and Bleeds: tick Use Document Bleed Settings. Export.

Affinity Publisher

  1. File → Export → PDF.
  2. Preset: PDF/X-1a, and include bleed. Export.

Adobe Acrobat Pro

  1. Tools → Print Production → Preflight.
  2. Under PDF/X compliance, choose Convert to PDF/X-1a and run it.
  3. Fix anything it can't convert, such as fonts that can't be embedded.

Word or Google Docs

  1. Neither can export PDF/X-1a directly. Export a normal PDF, then convert it in Acrobat Pro.

Quick answers

Does IngramSpark require PDF/X-1a?

IngramSpark asks for PDF/X-1a files. It's the safest format for every printer because it requires embedded fonts, CMYK color and flattened transparency.

Can Word export PDF/X-1a?

No. Save a normal PDF from Word, then convert it to PDF/X-1a with a tool such as Adobe Acrobat Pro or SparkPrep.
