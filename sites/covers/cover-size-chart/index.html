Look up your size

KDP paperback cover size chart

Find your trim size and page count to get the full cover size (back + spine + front + bleed) for an Amazon KDP paperback. Worked out from KDP's own paper thickness numbers.

Quick answer

KDP full cover width = 0.25" + 2 x trim width + spine; height = trim height + 0.25". Spine = pages x 0.002252" (white) or x 0.0025" (cream). Example: 5.5" x 8.5", 200 pages, white = 11.700" x 8.75".

Sizes are width x height in inches, including 0.125" bleed on every outer edge. Worked out with KDP's published paper thickness (white 0.002252", cream 0.0025", premium color 0.002347" per page). KDP's own cover template for your exact book is the final word; if it differs by a hair, use KDP's.

How to read the chart

  • Your page count isn't listed? Add or subtract: every extra page adds 0.002252" (white) or 0.0025" (cream) to the width.
  • Use your final PDF page count, including front matter and blank pages.
  • To get pixels at 300 DPI, multiply each number by 300.

Common mistakes

  • Using the trim size as the cover size. 6" x 9" is the book, not the cover.
  • Guessing the page count before the interior is final. Re-check the spine after the last edit.
  • Using a cream spine on a white book (or the other way round). On 300 pages that's 0.074" off.

Questions people ask

What is the cover size for a 5x8 book with 200 pages on KDP?

On white paper about 10.700 by 8.25 inches including bleed (spine 0.450 inch). On cream paper about 10.750 by 8.25 inches (spine 0.5 inch).

Does KDP give me a cover template?

Yes. KDP's cover template tool gives a PDF and PNG template for your trim size, page count and paper.
