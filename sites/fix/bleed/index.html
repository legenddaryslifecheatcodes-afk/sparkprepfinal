Fix: bleed

How to add bleed to your book cover (and pages)

Bleed is extra background that runs past the edge so the printer can trim it off cleanly. Almost every printer wants 0.125" (3.2 mm) on every outside edge.

Quick answer

To add bleed, make the file 0.125" bigger on every outer edge (0.25" wider and 0.25" taller for a cover), then stretch the background art all the way to the new outer edge. Keep words and faces well inside the trim line.

Check it in 30 seconds

Open your cover PDF in any PDF reader and look at the page size (File → Properties, or Document Properties). For a paperback cover, the height should be your book's height plus 0.25". A 6" x 9" book's cover is 9.25" tall. If it's exactly 9", there's no bleed.

The numbers

  • Cover width = 0.125 + back cover + spine + front cover + 0.125
  • Cover height = 0.125 + book height + 0.125
  • Interior with art to the edge = book width + 0.125 (outside edge only) by book height + 0.25

Fix it in Canva

  1. Turn on File → Settings → Show print bleed. A dashed line appears inside the edge: that's roughly where the cut goes.
  2. Drag every background photo and color block out past the outer edge of the design, not just to the dashed line.
  3. Move titles, author name and faces inward, well clear of the dashed line.
  4. Share → Download → PDF Print, and tick Crop marks and bleed. (Then check your printer's rules: most want the bleed but not the crop marks.)

Canva adds bleed around your design size. If you started from your printer's full cover size (which already includes bleed), you may end up with double bleed. Measure the downloaded PDF and compare it to the numbers above.

Fix it in InDesign or Affinity Publisher

  1. InDesign: File → Document Setup → Bleed and Slug → 0.125 in on all sides. Affinity: File → Document Setup → Bleed → 0.125 in.
  2. Pull background frames to the red bleed line on every outer edge.
  3. Export with "Use document bleed settings" ticked (InDesign) or "Include bleed" (Affinity), as PDF/X-1a.

Fix it in Word (interior pages with pictures to the edge)

  1. Layout → Size → More Paper Sizes. Add 0.125" to the width and 0.25" to the height (a 6" x 9" book becomes 6.125" x 9.25").
  2. Make edge-to-edge pictures overlap the paper edge slightly.
  3. Add 0.125" to your outside, top and bottom margins so the text doesn't move closer to the trim.

Word can't make a cover with proper bleed easily. Use Canva, Cover Studio or a printer template for the cover.

Why bleed errors come back

  • You made the file bigger but didn't stretch the background, so the extra space is white.
  • You stretched the background, but the PDF export cropped to the trim size.
  • Your spine changed (new page count or paper), so the whole cover is now the wrong width.
  • You added bleed to an interior that has no art to the edge. If nothing touches the edge, you don't need interior bleed, and adding it changes your page size.

Questions people ask

How much bleed does KDP need?

0.125 inch (3.2 mm) on every outer edge of the cover, and on the outer edges of interior pages that have art running to the edge.

Does every book need interior bleed?

No. Only books with pictures or color that touch the page edge. A normal novel doesn't need interior bleed.

Should I include crop marks?

Usually no. KDP and IngramSpark want the bleed area but not printer's marks in the uploaded file.
