How to embed fonts in your book PDF

A PDF can carry its fonts inside it, or just name them and hope the next computer has them. Printers need every font carried inside, even Arial and Times New Roman.

Quick answer

To fix "font not embedded", re-export the PDF with font embedding on: in Word, tick Embed fonts in the file (File → Options → Save) and export as PDF; in InDesign or Affinity, export with the PDF/X-1a preset. Check in Acrobat under File → Properties → Fonts.

Check it in 30 seconds

Open the PDF in Adobe Acrobat (Reader works too): File → Properties → Fonts. Every font should end with "(Embedded)" or "(Embedded Subset)". If any font doesn't, that's your problem.

Fix it in Word

  1. File → Options → Save. Tick Embed fonts in the file and untick Do not embed common system fonts.
  2. File → Save As → PDF → Options. Tick ISO 19005-1 compliant (PDF/A). This forces every font in.
  3. Save, then check in Acrobat again.

Fix it in InDesign or Affinity

  1. Export with the PDF/X-1a preset. It refuses to export with missing fonts, so it also tells you which ones are a problem.
  2. If InDesign shows a font as missing (pink highlight), install it or swap it before exporting.

Fix it in Canva

Canva's PDF Print download embeds fonts in almost every case. If a printer still flags a font, download again with Flatten PDF ticked: that turns text into artwork, so there's no font to embed. (Use this for covers. Don't flatten a whole interior, because the text gets heavier and less sharp.)

When a font won't embed

Some fonts have a license that forbids embedding. Your app will skip them quietly. You have two choices:

  • Swap the font for one with an open license (for example from Google Fonts, all of which may be embedded). SparkPrep's Cover Studio has 333 such fonts.
  • Turn that text into outlines (InDesign: Type → Create Outlines; Affinity: Layer → Convert to Curves). Only do this for a few words, like a cover title.

Free fonts aren't always free for books

A font from a "free fonts" website may be free for personal use only. A book you sell is commercial use. Check the license before you build your cover around it. If it says "personal use only", buy the commercial license or pick another font.

Questions people ask

Do I need to embed Arial or Times New Roman?

Yes. Printers want every font embedded, and some apps skip common fonts by default.

Are Google Fonts OK for a printed book?

Yes. Google Fonts use open licenses that allow commercial use and embedding in PDFs.
