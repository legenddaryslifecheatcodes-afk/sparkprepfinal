Quick answer

Most print file problems come from eight causes: missing bleed, small margins, fonts not embedded, live transparency, low-resolution pictures, RGB color or too much ink, the wrong PDF page size, and a wrong spine width. Each has a fix in Word, Canva, InDesign, Affinity or Acrobat.

Three rules before you fix anything

  1. Fix the original, not the PDF. Open the Word, Canva, InDesign or Affinity file you made the PDF from. Editing the PDF itself usually makes new problems.
  2. Fix the size first. Page size and cover size come before everything else. If the size changes, margins and spine move too.
  3. Check again after every fix. One fix can break another. Adding pages to fix margins changes your spine width, for example.

Questions people ask

Can I fix a print problem by editing the PDF?

Sometimes, with Acrobat Pro, for things like color conversion or embedding fonts. For size, bleed and margins, fix the original file and export a new PDF.

What is the most common book file problem?

Missing cover bleed, followed by interior margins and PDFs made at the wrong page size.
