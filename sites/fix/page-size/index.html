Fix: page size

How to fix the wrong PDF page size

If your book is 6" x 9" but your PDF pages are 8.5" x 11" (letter), the printer has to shrink or crop every page. Your text ends up off-center, too small, or too close to the edge.

Quick answer

Your PDF page size must equal your book's trim size (for example 6" x 9"), or trim size plus bleed if art touches the edge. Set the paper size in your original file to the trim size, re-flow the text, then export a new PDF.

Check it in 10 seconds

Open the PDF and look at Document Properties (Acrobat: File → Properties → Description → Page Size). It must match your trim size exactly. Every page, not just the first: a pasted-in section can carry its own size.

Fix it in Word

  1. Save a copy first. Changing page size re-flows every page.
  2. Layout → Size → More Paper Sizes. Type your trim width and height. Apply to: Whole document.
  3. Reset margins for the new size (see margins). Letter-size margins are far too big for a 5" x 8" book.
  4. Check every chapter: pictures, tables and page breaks will have moved. Fix any orphaned lines and empty pages.
  5. Your page count probably changed. Note the new count; your cover's spine depends on it.
  6. File → Save As → PDF. In Options, choose "Standard (publishing online and printing)".

Fix it in InDesign or Affinity

  1. File → Document Setup. Change width and height to your trim size.
  2. Use "Adjust layout" (InDesign) or let Affinity rescale content, then check each spread.
  3. Export again as PDF/X-1a.

Questions people ask

Can I upload a letter-size PDF for a 6x9 book?

You shouldn't. The printer will shrink or reject it, and the result is usually off-center text and margin errors.

Why did my page count change when I changed the page size?

Smaller pages hold fewer words, so the text re-flows onto more pages. Update your cover's spine width to match.
