Choosing a printer

KDP or IngramSpark for your first book?

Both print your book one copy at a time when someone orders it, so neither needs you to buy stock. The difference is where your book is sold and how strict the file rules are.

Quick answer

Start with Amazon KDP if you mainly want to sell on Amazon: it's free and simpler. Add IngramSpark if you want bookstores and libraries to order your book, or want a dust jacket hardcover. Many authors use both, with their own ISBN, and build files to IngramSpark's stricter rules.

Our honest advice

  • Just want your book on Amazon, fast? KDP.
  • Want local bookstores, libraries or events to stock it? Add IngramSpark. Stores order through Ingram.
  • Planning both? Buy your own ISBNs so the same edition has the same number everywhere, and build the interior to IngramSpark's rules from the start. Here's why.

Three questions to decide

Where will your readers buy it?

If your readers find books on Amazon (most genre fiction, most self-help), KDP alone may be all you need. If you're planning readings, local bookstores, school visits or library copies, those buyers order through Ingram, so you'll want IngramSpark.

How much setup are you ready for?

KDP walks you through one book at a time with fewer choices. IngramSpark asks more questions (discounts, returns, paper types) and checks files harder. If this is your very first book and you're nervous, start with KDP and add IngramSpark once it's live.

What kind of book is it?

A paperback novel works anywhere. A hardcover with a dust jacket needs IngramSpark. A full-color picture book works on both, but check each printer's color paper and ink rules before you design.

Using both without trouble

  1. Format the interior with at least 0.5" margins on every side (bigger inside for thick books).
  2. Keep color under 240% total ink; save black and white as grayscale.
  3. Make two covers, one from each printer's template, because the spine width differs.
  4. Use the same ISBN for the same format on both, if it's your own ISBN.
  5. Preflight each set of files for its printer before uploading.

Questions people ask

Should I use KDP or IngramSpark for my first book?

KDP is the simpler start if you mainly sell on Amazon. Add IngramSpark if you want bookstores and libraries to be able to order it.

Can I use both KDP and IngramSpark?

Yes. Many authors do. Build the interior to IngramSpark's stricter rules and make a separate cover for each printer.
